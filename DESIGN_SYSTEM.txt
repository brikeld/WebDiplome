1.3 Layout + spacing primitives

Page container
- .page max-width: 1012px
- .page padding: 16px 16px 16px 72px
  - left padding makes room for fixed sidebar rail

Common vertical rhythm
- Many capsule stacks use margin-bottom: 36px
  - Example: .home-tab margin-bottom: 36px
  - Example: .profile-header-stack margin-bottom: 36px

Capsule insets
- Posts capsule padding: 24px 28px 28px
- Profile content capsule padding: 24px 28px 28px

Micro gaps
- .icon-rail gap: 2px, padding: 4px
- .tabs-row gap: 2px, padding: 4px
- Post header row gap: clamp(16px, 2vw, 24px)


1.4 Shape / radius

Radii tokens and conventions
- Capsule radius token: --capsule-radius = 56px
  - used for outer shells like .posts-capsule and .profile-content-capsule

“Pill / stadium” convention
- Use border-radius: 9999px for fully-rounded pills:
  - post bubble (.post-card-bubble)
  - profile hero capsule (.profile-hero-capsule)
  - tabs row container (.tabs-row)
  - small pills (meta pills, last-analysis pill, etc.)

Circles
- border-radius: 50% for avatars / score / badges


1.5 Borders + shadows

Borders
- Outer capsules: 1px solid var(--border)
  - .posts-capsule, .profile-content-capsule
- Accent bubbles (posts, profile hero, badge capsule): 3px solid accent variable
  - Post bubble border: 3px solid var(--post-accent)
  - Profile hero capsule border: 3px solid var(--persona-accent)
  - Badge capsule border: 3px solid var(--persona-accent)
- Tabs/rail containers: 2px solid rgba(0, 0, 0, 0.08)

Shadow
- Persona toggle button:
  - box-shadow: 0 10px 24px rgba(0, 0, 0, 0.14)


1.6 Background tinting rule (important for “look”)

Instead of using solid accent backgrounds, most large pills use a subtle tint:
- Post bubble fill:
  - background: color-mix(in srgb, var(--post-accent) 15%, #fff)
- Post avatar fill:
  - background: color-mix(in srgb, var(--post-accent) 20%, #fff)
- Profile hero capsule fill:
  - background: color-mix(in srgb, var(--persona-accent) 15%, #fff)

This makes the UI feel “paper + ink” rather than flat neon blocks.

----------------------------------------------------------------------
3) Interaction + accessibility conventions
----------------------------------------------------------------------

Focus rings
- Buttons use :focus-visible outlines:
  - outline: 2px solid #000
  - outline-offset: 2px to 3px depending on component

Hover/active feedback
- Active “press” is typically a tiny scale or translate:
  - persona toggle: scale(0.98) while active
  - rail buttons: translateY(1px) while active

4) Implementation notes for the Mac app
----------------------------------------------------------------------

If you want the Mac app to match precisely, mirror these as “design tokens”:

Colors
- Background: #F2F0EF
- Surface: #FFFFFF
- Text primary: #000000
- Text secondary: #888888
- Border neutral: #CCCAC7
- Persona accents:
  - Productivity: #2323FF

  - Popularity:   #0FA020

  - Productivity: #D9D9FD
  - Security:     #FFE3D7
  - Popularity:   #E1FFE4

Corner radius
- Capsule radius: 56px
- Pill radius: “max” (9999px equivalent)
- Circle: 50%

Stroke widths
- Neutral capsule border: 1px
- Accent borders: 3px

Tinted fills (most important “feel” detail)
- Large accent pills use a white mix with ~15% accent, not solid accent.

Typography
- Body baseline: 13px @ 600 weight, line-height 1.6
- Posts:
  - 28px @ 700, line-height 0.95, letter-spacing -0.01em
  - name 19.2px @ 700

Spacing
- Outer page padding: 16px all around, but left is 72px to accommodate sidebar

- Common section spacing: 36px between stacks
