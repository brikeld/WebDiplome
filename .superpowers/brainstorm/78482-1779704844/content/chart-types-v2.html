New chart ideas FROM YOUR DATA

These data fields exist in your data.json but no chart uses them yet. Each one makes a distinct, creepy-yet-beautiful visualization.

Productivité
File Creation Heatmap
24-column heatmap — one cell per hour of the day. Height or darkness = how many files were created at that hour. Exposes your work rhythm and late-night sessions at a glance.
Data: PAST_HISTORY.recent_files_7days[].date (timestamps) — extract hours, bin into 24 buckets.
Productivité
Folder Depth Map
Sunburst or nested rectangles showing where your recent files live — top-level directory → subfolder hierarchy. Shows which projects are active by file density.
Data: PAST_HISTORY.recent_files_7days[].path — parse directories, build a 2-level treemap.
Popularité
Chrome vs Safari Split
Vertical split bar — left half Chrome visits, right half Safari. Inside each half, top domains ranked. Exposes browser loyalty and which domains you prefer in which browser.
Data: PAST_HISTORY.browser_history.chrome[] vs .safari[] — count and compare.
Popularité
App Open Recency Grid
7-column grid (Mon→Sun), each row an app. A filled cell = app was opened that day. Like a GitHub contribution graph but for your app usage over the past week.
Data: PAST_HISTORY.app_usage_7days[].last_used — parse date, map to day-of-week per app.
Sécurité
Download Type Risk Chart
Classify your recent downloads by file type (.dmg, .pkg, .zip, .pdf, .exe) and risk level. A stacked bar showing "safe / suspicious / executable" proportions with specific filenames as labels.
Data: PAST_HISTORY.recent_downloads[].name — classify by extension into risk buckets.

Installed App Age Map
Timeline strip showing when apps were installed vs last updated. Apps not updated in 6+ months highlighted. Long-stale installs are a security surface area — this makes that visible.
Data: If MACHINE_IDENTITY.installed_apps includes version/date metadata — or derive from app recency.
